START THE APPLICATION

Extract. Open. Explore.

This page is the project welcome guide. The functional application is the Python/Tkinter desktop program.

  1. Extract the entire project ZIP to a regular folder.
  2. Use Python 3.10 or newer with Tcl/Tk support.
  3. Open a terminal in this project folder and run:
python app.py

Use python3 app.py on macOS/Linux if needed. Windows: double-click Start_Windows.bat. The README includes installation checks and troubleshooting.

01 / ENUMERATE

Find every point.

Choose a prime field and a nonsingular curve. Inspect all coordinates, their discrete plot, and the separate identity O.

02 / ADD

Follow the field arithmetic.

Add two points, double a point, or try an inverse pair. Read the slope, modular inverse and coordinate calculations.

03 / MULTIPLY

See the binary steps.

Compute an integer multiple, then walk through each bit. Watch the addend double and the accumulator change.

THE DEFAULT EXAMPLE

A small field with a complete story.

y² ≡ x³ + 2x + 2 (mod 17)

18 finite points + O = 19 group elements. Start from P=(5,1).

LEARN THE IMPLEMENTATION

Read the code in a useful order.

  1. ecc.py: validation → Euclidean inverse → enumeration → addition → multiplication.
  2. app.py: widget layout → curve application → calculation callbacks → plot → exports.
  3. tests/test_ecc.py: independent references and mathematical properties.
  4. tests/test_gui.py: real-Tk state, layout and integration checks.
